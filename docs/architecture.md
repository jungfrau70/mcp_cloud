# AI 활용 교육 교구 시스템 아키텍처

## 1. 개요

AI 활용 교육 교구 시스템은 교육 커리큘럼 작성자, 교육자, 수강자 간의 원활한 상호작용을 지원하기 위해 모듈화된 아키텍처를 채택합니다. 본 문서는 각 컴포넌트의 역할과 데이터 흐름을 설명합니다.

## 2. 핵심 컴포넌트 (Core Components)

![AI 활용 교육 교구 시스템 아키텍처 다이어그램](architecture_diagram.svg)  
*(위 다이어그램은 `architecture_diagram.md`의 Mermaid 코드로 생성됩니다.)*

### 2.1. Frontend (Nuxt 3 / Vue.js)

- **사용자 인터페이스 (UI)**: 교육 커리큘럼 작성자, 교육자, 수강자가 플랫폼과 상호작용하는 웹 애플리케이션입니다.
- **주요 역할**:
    - **수강자 대시보드**: 학습 콘텐츠 조회, AI 에이전트와 대화, 실습 환경을 통한 학습 진행.
    - **교육자 대시보드**: 교육 콘텐츠(커리큘럼) 관리, 수강자 활동 모니터링.
    - **커리큘럼 작성자 대시보드**: 교육 자료 생성, 템플릿 관리, AI 콘텐츠 생성 도구.
    - **상태 관리**: 사용자의 로그인 상태, 현재 학습 중인 내용 등을 관리합니다.
    - **API 클라이언트**: 백엔드 API와 통신하여 데이터를 주고받습니다.

### 2.2. Backend (FastAPI / Python)

- **중앙 API 서버**: 플랫폼의 모든 비즈니스 로직을 처리하는 핵심 서버입니다.
- **주요 역할**:
    - **API 제공**: 프론트엔드의 요청에 따라 교육 콘텐츠, 사용자 정보 등을 제공합니다.
    - **인증/권한 관리**: 커리큘럼 작성자, 교육자, 수강자의 역할을 구분하고 접근 권한을 제어합니다.
    - **AI 에이전트 오케스트레이션**: 사용자의 요청을 받아 AI 에이전트 레이어에 전달하고, 그 결과를 다시 프론트엔드에 반환합니다.
    - **데이터베이스 관리**: PostgreSQL 및 Redis와의 모든 상호작용을 담당합니다.
    - **교육 자료 관리**: 마크다운 기반 교육 자료의 생성, 수정, 검증을 담당합니다.

### 2.3. AI 에이전트 레이어

- **지능형 교육 지원 엔진**: 플랫폼의 '뇌' 역할을 수행합니다.
- **주요 역할**:
    - **LLM (OpenAI/Anthropic)**: 자연어 이해 및 생성을 담당합니다. 수강자의 질문에 답변하고, 교육자를 위한 교육 자료 초안을 작성합니다.
    - **교육 자료 생성**: 주제와 난이도에 맞는 교육 자료를 자동으로 생성합니다.
    - **실습 가이드 작성**: 단계별 실습 지침을 자동으로 작성합니다.
    - **평가 문항 생성**: 학습 목표에 맞는 평가 문항을 자동으로 생성합니다.

### 2.4. Data Stores

- **데이터 영속성 계층**: 플랫폼의 모든 데이터를 저장하고 관리합니다.
- **주요 역할**:
    - **PostgreSQL (RDBMS)**: 구조화된 데이터를 저장합니다. (예: 사용자 정보, 교육 모듈, 커리큘럼, 수강자 진도 등)
    - **Redis (Cache)**: 성능 최적화를 위한 캐시 데이터를 저장합니다.
    - **로컬 파일 시스템**: 마크다운 기반 교육 자료를 저장합니다.

### 2.5. 실습 환경

- **안전한 실습 공간**: 수강자들이 학습한 내용을 안전하게 실습할 수 있는 환경입니다.
- **주요 역할**:
    - **코드 에디터**: 웹 기반 코드 에디터를 제공합니다.
    - **실행 환경**: 격리된 환경에서 코드를 실행하고 결과를 확인할 수 있습니다.
    - **피드백 시스템**: 실습 결과에 대한 즉각적인 피드백을 제공합니다.

### 2.6. 교육 자료 관리 시스템

- **문서 연결 무결성**: 모든 앵커 링크 100% 정상 작동
- **제목 일관성**: 교육 과정별 일관된 제목 체계
- **실습 가이드**: 단계별 명확한 실습 지침
- **진도 관리**: 학습자 진도 추적 및 관리

## 3. 데이터 및 상호작용 흐름 (Data & Interaction Flow)

1.  **교육 콘텐츠 조회**: 수강자가 프론트엔드에서 특정 교육 모듈을 클릭합니다.
    - `Frontend` -> `Backend`: 교육 모듈 데이터 요청 (GET /api/modules/{id})
    - `Backend` -> `PostgreSQL`: 해당 ID의 콘텐츠 조회
    - `PostgreSQL` -> `Backend` -> `Frontend`: 콘텐츠 데이터 반환 및 화면에 렌더링.

2.  **AI 에이전트에게 질문**: 수강자가 학습 중 궁금한 점을 AI 에이전트 채팅창에 입력합니다.
    - `Frontend` -> `Backend`: 질문 내용 전송 (POST /api/ai/ask)
    - `Backend` -> `AI 에이전트 레이어 (LLM)`: 질문을 전달하여 답변 생성 요청
    - `AI 에이전트 레이어` -> `Backend` -> `Frontend`: 생성된 답변을 수강자에게 실시간으로 표시.

3.  **실습 환경 사용**: 수강자가 코드 에디터에 코드를 입력하고 실행합니다.
    - `Frontend` -> `Backend`: 코드 실행 요청 전송
    - `Backend` -> `실습 환경`: 격리된 환경에서 코드 실행
    - `실습 환경` -> `Backend` -> `Frontend`: 실행 결과를 실시간으로 출력.
