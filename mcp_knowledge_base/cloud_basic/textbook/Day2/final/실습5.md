# 📊 BigQuery 서버리스 분석 실습 가이드 (웹콘솔 + CLI)

## 📋 개요

**목적**: Google Cloud Platform의 BigQuery를 활용하여 대용량 데이터 분석 및 서버리스 데이터 웨어하우스 경험
**범위**: 
- BigQuery 데이터셋 및 테이블 생성

- SQL 쿼리 실행 및 최적화

## 🏗️ 1단계: GCP 환경 준비

### 1.1 GCP 프로젝트 설정

#### 🌐 웹콘솔 방식
```markdown
1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. 프로젝트 선택 또는 새 프로젝트 생성
3. "BigQuery" 검색하여 서비스 페이지 접속
4. BigQuery API가 활성화되었는지 확인
```

#### 💻 CLI 방식
```bash
# 프로젝트 설정 (기존 프로젝트 사용 또는 새로 생성)
gcloud config set project YOUR_PROJECT_ID

# BigQuery API 활성화
gcloud services enable bigquery.googleapis.com

# 프로젝트 확인
gcloud config get-value project

# BigQuery API 상태 확인
gcloud services list --enabled --filter="name:bigquery.googleapis.com"
```

### 1.2 서비스 계정 생성 (CLI용)

#### 🌐 웹콘솔 방식
```markdown
1. IAM 및 관리 → "서비스 계정" 클릭
2. "서비스 계정 만들기" 클릭
3. 이름: "bigquery-admin"
4. 설명: "BigQuery 관리용 서비스 계정"
5. "만들고 계속" 클릭
6. 역할: "BigQuery 관리자" 선택
7. "완료" 클릭
8. 키 생성: JSON 키 다운로드
```

#### 💻 CLI 방식
```bash
# 서비스 계정 생성
gcloud iam service-accounts create bigquery-admin \
  --display-name="BigQuery Admin Service Account"

# 서비스 계정에 BigQuery 관리자 역할 부여
gcloud projects add-iam-policy-binding $(gcloud config get-value project) \
  --member="serviceAccount:bigquery-admin@$(gcloud config get-value project).iam.gserviceaccount.com" \
  --role="roles/bigquery.admin"

# 서비스 계정 키 생성
gcloud iam service-accounts keys create bigquery-key.json \
  --iam-account=bigquery-admin@$(gcloud config get-value project).iam.gserviceaccount.com

# 환경 변수 설정
export GOOGLE_APPLICATION_CREDENTIALS="$(pwd)/bigquery-key.json"
```

## 🗂️ 2단계: BigQuery 데이터셋 생성

### 2.1 데이터셋 생성

#### 🌐 웹콘솔 방식
```markdown
1. BigQuery 콘솔 접속
2. 프로젝트 선택
3. "데이터셋 만들기" 클릭
4. 데이터셋 ID: "sales_analytics"
5. 데이터 위치: "asia-northeast3 (Seoul)"
6. "데이터셋 만들기" 클릭
```

#### 💻 CLI 방식
```bash
# 데이터셋 생성
bq mk --location=asia-northeast3 sales_analytics

# 데이터셋 목록 확인
bq ls

# 데이터셋 세부 정보 확인
bq show sales_analytics
```

### 2.2 테이블 스키마 정의

## 🔍 4단계: SQL 쿼리 실행 및 분석

### 4.1 기본 쿼리 실행

#### 🌐 웹콘솔 방식
```markdown
1. BigQuery 콘솔 → "쿼리 편집기" 클릭
2. 쿼리 입력 및 실행
3. 결과 확인 및 저장
```

#### 💻 CLI 방식
```bash
# 기본 SELECT 쿼리
bq query --use_legacy_sql=false "
SELECT 
  region,
  COUNT(*) as order_count,
  SUM(quantity * unit_price) as total_sales
FROM sales_analytics.sales
GROUP BY region
ORDER BY total_sales DESC
"

# 고객별 주문 분석
bq query --use_legacy_sql=false "
SELECT 
  customer_id,
  COUNT(*) as order_count,
  SUM(quantity * unit_price) as total_amount,
  AVG(quantity * unit_price) as avg_order_value
FROM sales_analytics.sales
GROUP BY customer_id
ORDER BY total_amount DESC
LIMIT 10
"
```

### 4.2 고급 분석 쿼리

#### 💻 CLI 방식
```bash
# 월별 매출 트렌드 분석
bq query --use_legacy_sql=false "
SELECT 
  EXTRACT(MONTH FROM order_date) as month,
  EXTRACT(YEAR FROM order_date) as year,
  COUNT(*) as order_count,
  SUM(quantity * unit_price) as monthly_sales,
  AVG(quantity * unit_price) as avg_order_value
FROM sales_analytics.sales
GROUP BY year, month
ORDER BY year, month
"

# 상품별 인기도 분석
bq query --use_legacy_sql=false "
SELECT 
  product_id,
  COUNT(*) as order_count,
  SUM(quantity) as total_quantity,
  SUM(quantity * unit_price) as total_revenue,
  AVG(unit_price) as avg_price
FROM sales_analytics.sales
GROUP BY product_id
ORDER BY total_revenue DESC
"

# 윈도우 함수를 사용한 순위 분석
bq query --use_legacy_sql=false "
SELECT 
  customer_id,
  order_id,
  quantity * unit_price as order_amount,
  RANK() OVER (PARTITION BY customer_id ORDER BY quantity * unit_price DESC) as rank_in_customer,
  RANK() OVER (ORDER BY quantity * unit_price DESC) as overall_rank
FROM sales_analytics.sales
ORDER BY customer_id, rank_in_customer
"
```

```bash
  --time_partitioning_type=DAY \
  --time_partitioning_field=order_date \
  sales_analytics.sales_partitioned

# 클러스터링된 테이블 생성

  --schema=sales_schema.json \
  --clustering_fields=region,customer_id \
  sales_analytics.sales_clustered

# 쿼리 최적화 예제
bq query --use_legacy_sql=false "
SELECT 
  region,
  COUNT(*) as order_count
FROM sales_analytics.sales_partitioned
WHERE order_date >= '2024-01-01'
  AND order_date < '2024-02-01'
GROUP BY region
"
```

## 🤖 7단계: 머신러닝 모델 생성 (선택사항)

### 7.1 BigQuery ML 활용

#### 💻 CLI 방식
```bash
# 선형 회귀 모델 생성 (매출 예측)
bq query --use_legacy_sql=false "
CREATE OR REPLACE MODEL sales_analytics.sales_prediction_model
OPTIONS(model_type='linear_reg') AS
SELECT 
  quantity * unit_price as total_amount,
  quantity,
  unit_price,
  EXTRACT(DAYOFWEEK FROM order_date) as day_of_week,
  CASE 
    WHEN region = 'Seoul' THEN 1 ELSE 0 
  END as is_seoul
FROM sales_analytics.sales
WHERE order_date >= '2024-01-01'
"

# 모델 평가
bq query --use_legacy_sql=false "
SELECT *
FROM ML.EVALUATE(MODEL sales_analytics.sales_prediction_model)
"

# 모델을 사용한 예측
bq query --use_legacy_sql=false "
SELECT 
  predicted_total_amount,
  total_amount
FROM ML.PREDICT(MODEL sales_analytics.sales_prediction_model,
  (SELECT 
     quantity,
     unit_price,
     EXTRACT(DAYOFWEEK FROM order_date) as day_of_week,
     CASE WHEN region = 'Seoul' THEN 1 ELSE 0 END as is_seoul,
     quantity * unit_price as total_amount
   FROM sales_analytics.sales
   WHERE order_date >= '2024-02-01'
   LIMIT 10))
"
```
