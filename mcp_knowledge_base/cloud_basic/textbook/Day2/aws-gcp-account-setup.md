## 개요
Cloud Basic 2일차의 클라우드 계정 설정 및 기본 서비스 실습을 위한 가이드입니다.

## 학습 목표
- AWS Free Tier 계정 생성 및 설정
- GCP 계정 생성 및 $300 크레딧 활성화
- 기본 서비스 콘솔 탐색

## 실습 내용
1. **AWS 계정 설정**
   - Free Tier 계정 생성
   - 기본 보안 설정
   - 콘솔 탐색

2. **GCP 계정 설정**
   - 계정 생성 및 인증
   - 프로젝트 생성
   - API 활성화

3. **비용 관리**
   - 예산 설정
   - 알림 구성
