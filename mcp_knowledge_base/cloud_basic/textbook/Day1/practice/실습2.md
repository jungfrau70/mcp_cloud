# 🌐 GCP 정적 웹사이트 배포 사용자 가이드 (웹콘솔 + CLI)

## 📋 개요

**목적**: Google Cloud Platform의 Cloud Storage를 활용하여 정적 웹사이트를 배포하고 관리
**범위**: 
- GCP 프로젝트 생성 및 설정
- Cloud Storage 버킷 생성 및 웹사이트 기능 활성화
- 정적 파일 업로드 및 퍼블릭 접근 설정
- 웹사이트 배포 및 테스트

---

## 🏗️ 1단계: GCP 환경 준비

### 1.1 GCP 계정 생성

#### 🌐 웹콘솔 방식
```markdown
1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. Google 계정으로 로그인
3. "무료 체험판 시작" 클릭
4. 개인 정보 입력
5. 신용카드 등록 ($300 크레딧 제공)
6. 약관 동의 후 "시작하기" 클릭
```

#### 💻 CLI 방식
```bash
# Google Cloud SDK 설치 (Windows)
# https://cloud.google.com/sdk/docs/install

# Google Cloud SDK 설치 (macOS)
brew install google-cloud-sdk

# Google Cloud SDK 설치 (Ubuntu)
curl https://sdk.cloud.google.com | bash
exec -l $SHELL

# 초기화 및 로그인
gcloud init
gcloud auth login

# 프로젝트 목록 확인
gcloud projects list
```

### 1.2 프로젝트 생성

#### 🌐 웹콘솔 방식
```markdown
1. GCP Console 상단 프로젝트 선택 드롭다운 클릭
2. "새 프로젝트" 클릭
3. 프로젝트 이름: "my-static-website"
4. "만들기" 클릭
5. 생성된 프로젝트 선택
```

#### 💻 CLI 방식
```bash
# 프로젝트 생성
gcloud projects create my-static-website --name="My Static Website"

# 프로젝트 설정
gcloud config set project my-static-website

# 프로젝트 확인
gcloud config get-value project
```

## 🗂️ 2단계: Cloud Storage 버킷 생성

### 2.1 버킷 생성

#### 🌐 웹콘솔 방식
```markdown
1. 좌측 메뉴 → "Cloud Storage" → "버킷" 클릭
2. "버킷 만들기" 클릭
3. 버킷 이름: "my-static-website-bucket-123"
4. 위치 유형: "Region"
5. 위치: "asia-northeast3 (Seoul)"
6. 스토리지 클래스: "Standard"
7. 액세스 제어: "Uniform"
8. "만들기" 클릭
```

#### 💻 CLI 방식
```bash
# 버킷 생성
gsutil mb -l asia-northeast3 gs://my-static-website-bucket-123

# 버킷 목록 확인
gsutil ls

# 버킷 세부 정보 확인
gsutil ls -L gs://my-static-website-bucket-123
```

### 2.2 웹사이트 설정

#### 🌐 웹콘솔 방식
```markdown
1. 생성된 버킷 클릭
2. "편집" 탭 클릭
3. "웹사이트 구성 편집" 클릭
4. 메인 페이지: "index.html"
5. 오류 페이지: "404.html"
6. "저장" 클릭
```

#### 💻 CLI 방식
```bash
# 웹사이트 설정 JSON 파일 생성
cat > website-config.json << 'EOF'
{
  "mainPageSuffix": "index.html",
  "notFoundPage": "404.html"
}
EOF

# 웹사이트 설정 적용
gsutil web set -m index.html -e 404.html gs://my-static-website-bucket-123

# 웹사이트 설정 확인
gsutil web get gs://my-static-website-bucket-123
```

### 3.2 파일 업로드

#### 🌐 웹콘솔 방식
```markdown
1. 버킷 내부로 이동
2. "파일 업로드" 클릭
3. index.html, 404.html 파일 선택
4. "업로드" 클릭
5. 업로드 완료 확인
```

#### 💻 CLI 방식
```bash
# 파일 업로드
gsutil cp index.html gs://my-static-website-bucket-123/
gsutil cp 404.html gs://my-static-website-bucket-123/

# 업로드된 파일 확인
gsutil ls gs://my-static-website-bucket-123/

# 파일 권한 확인
gsutil ls -L gs://my-static-website-bucket-123/index.html
```

## 🌐 4단계: 퍼블릭 접근 설정

### 4.1 버킷 공개 설정

#### 🌐 웹콘솔 방식
```markdown
1. 버킷 → "권한" 탭 클릭
2. "액세스 권한 부여" 클릭
3. 새 주체: "allUsers" 입력
4. 역할: "Storage 객체 뷰어" 선택
5. "저장" 클릭
6. 경고 메시지 확인 후 "허용" 클릭
```

#### 💻 CLI 방식
```bash
# 버킷에 퍼블릭 읽기 권한 부여
gsutil iam ch allUsers:objectViewer gs://my-static-website-bucket-123

# 권한 확인
gsutil iam get gs://my-static-website-bucket-123
```

## 🔗 5단계: 웹사이트 접속 및 확인

### 5.1 웹사이트 URL 확인

#### 🌐 웹콘솔 방식
```markdown
1. 버킷 → "편집" 탭 클릭
2. "웹사이트 구성" 섹션에서 URL 확인
3. 웹사이트 URL 복사
4. 새 브라우저 탭에서 URL 접속
5. 정상 표시 확인
```

#### 💻 CLI 방식
```bash
# 웹사이트 URL 확인
gsutil web get gs://my-static-website-bucket-123

# 웹사이트 접속 테스트
curl -I http://storage.googleapis.com/my-static-website-bucket-123/index.html

# 또는
curl -I http://my-static-website-bucket-123.storage.googleapis.com/index.html

# 웹사이트 내용 확인
curl http://storage.googleapis.com/my-static-website-bucket-123/index.html
```

### 5.2 웹사이트 테스트

#### 💻 CLI 방식
```bash
# 메인 페이지 접속 테스트
echo "메인 페이지 테스트:"
curl -s http://storage.googleapis.com/my-static-website-bucket-123/index.html | head -20

# 404 페이지 테스트
echo -e "\n404 페이지 테스트:"
curl -s http://storage.googleapis.com/my-static-website-bucket-123/nonexistent.html | head -10

# 웹사이트 성능 테스트
echo -e "\n응답 시간 테스트:"
time curl -s -o /dev/null http://storage.googleapis.com/my-static-website-bucket-123/index.html
```

## 🌐 7단계: 커스텀 도메인 연결 (선택 사항)

### 7.1 도메인 설정

#### 🌐 웹콘솔 방식
```markdown
1. Google Domains 또는 타사 도메인 구매
2. DNS에 CNAME 레코드 등록
   - www.example.com → c.storage.googleapis.com
3. Cloud Storage 버킷 이름을 도메인과 동일하게 설정
4. HTTPS 적용 시 Cloud Load Balancer + SSL 인증서 연동
```

#### 💻 CLI 방식
```bash
# 커스텀 도메인용 버킷 생성 (예시)
gsutil mb -l asia-northeast3 gs://www.example.com

# 웹사이트 설정
gsutil web set -m index.html -e 404.html gs://www.example.com

# 파일 업로드
gsutil cp index.html gs://www.example.com/
gsutil cp 404.html gs://www.example.com/

# 퍼블릭 권한 설정
gsutil iam ch allUsers:objectViewer gs://www.example.com
```
