## 🌐 Cloud 실무자 기초교육 커리큘럼

**대상자:** 클라우드 초급 실무자
**대상 클라우드:** AWS / Azure / GCP
**목표:** 각 클라우드의 기본 환경을 이해하고, FinOps(비용 관리), IAM(권한 관리), Storage(스토리지 사용) 영역의 실무 기초를 익힌다.

---

## ✅ 전체 커리큘럼 개요

| Step   | 주제                                 | 목적                         |
| ------ | ---------------------------------- | -------------------------- |
| Step 0 | FinOps / Setup                     | 클라우드 계정 및 비용 구조 이해, 환경 구성  |
| Step 1 | IAM (Identity & Access Management) | 사용자 및 권한 관리 구조 이해 및 실습     |
| Step 2 | Storage                            | 주요 스토리지 서비스 이해 및 파일 업로드 실습 |
