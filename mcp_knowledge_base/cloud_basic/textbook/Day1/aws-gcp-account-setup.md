## 🚀 AWS 계정 생성 및 설정

<details>
<summary>📖 AWS 계정 생성 개요</summary>

### AWS 계정 생성 방법
- **웹콘솔 방식**: AWS 홈페이지에서 직접 생성
- **CLI 방식**: AWS CLI를 통한 자동화
- **Free Tier**: 12개월간 무료 사용 가능

### 중요 사항
- **신용카드 정보 필수**: Free Tier 사용을 위해 필요
- **실제 비용 발생 가능**: Free Tier 한도 초과 시
- **계정 보안**: MFA(다단계 인증) 설정 권장

</details>
