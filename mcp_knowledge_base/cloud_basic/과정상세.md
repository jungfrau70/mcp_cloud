# 클라우드 실무력 강화! AWS & GCP 활용법(기초)

## 📌 과정 개요

본 과정은 클라우드 입문자를 대상으로 AWS와 GCP의 **핵심 기초 서비스**를 학습하고 실습하는 교육 과정입니다. 계정 생성부터 IAM, 가상머신, 스토리지, 네트워크, 보안, 데이터베이스까지 클라우드의 기본 개념을 이해하고 직접 실습을 통해 기초 역량을 쌓을 수 있습니다.

* **교육일정**: 9/2(수) \~ 9/3(목) (2일, 총 14시간)
* **교육시간**: 9:00 \~ 17:00 (7시간/일)
* **교육방식**: 오프라인 실습 중심

## 📌 학습 목표

* 클라우드 컴퓨팅의 기본 개념 이해
* AWS와 GCP 계정 생성 및 기본 설정 수행
* IAM을 통한 사용자 및 권한 관리 기초 습득
* 가상머신, 스토리지, 네트워크, 데이터베이스 서비스의 기본 활용
* 클라우드 보안의 기초 개념 이해
* 간단한 웹 애플리케이션을 배포할 수 있는 기초 능력 확보

## 📌 커리큘럼

### 📅 1일차: 클라우드 기초 및 계정 관리 ☁️

1. **클라우드 개념 및 계정 생성**

   * 클라우드 컴퓨팅 개요와 장점
   * AWS와 GCP 서비스 개요
   * 실습: AWS/GCP 계정 생성 및 콘솔 탐색
2. **IAM 기초**

   * 사용자, 그룹, 역할, 정책 개념
   * 실습: AWS IAM 사용자 생성 및 권한 부여
   * 실습: GCP IAM 서비스 계정 생성 및 권한 관리
3. **가상머신 서비스 기초**

   * AWS EC2 / GCP Compute Engine 소개
   * 인스턴스 타입 및 이미지 개념
   * 실습: VM 생성 및 접속
4. **스토리지 서비스 기초**

   * AWS S3 / GCP Cloud Storage 소개
   * 객체 스토리지 개념과 활용 사례
   * 실습: 버킷 생성 및 파일 업로드/다운로드

---

### 📅 2일차: 네트워크 및 보안 기초 🔒

1. **네트워킹 기초**

   * AWS VPC / GCP VPC 개념
   * 서브넷, 라우팅, 게이트웨이 기본
   * 실습: VPC 및 서브넷 구성
2. **보안 그룹 및 방화벽**

   * AWS Security Groups / GCP Firewall Rules
   * 인바운드/아웃바운드 규칙 설정
   * 실습: 보안 그룹 및 방화벽 규칙 생성
3. **데이터베이스 서비스 기초**

   * AWS RDS / GCP Cloud SQL 소개
   * 관계형 데이터베이스 관리
   * 실습: MySQL 인스턴스 생성 및 연결
4. **종합 실습 및 정리**

   * 웹 서버 + 데이터베이스 구성 종합 실습
   * AWS/GCP 서비스 비교 정리
   * 실습: 간단한 웹 애플리케이션 배포
