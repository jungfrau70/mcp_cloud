## 🛠️ 기술 스택

### 클라우드 플랫폼
- **AWS** - Amazon Web Services
- **GCP** - Google Cloud Platform
- **Free Tier** - 무료 크레딧 활용

### 핵심 서비스
- **EC2/Compute Engine** - 가상머신 서비스
- **S3/Cloud Storage** - 객체 스토리지
- **RDS/Cloud SQL** - 관리형 데이터베이스
- **VPC** - 가상 네트워크

### 보안 & 관리
- **IAM** - 사용자 및 권한 관리
- **Security Groups** - 방화벽 규칙
- **VPC** - 네트워크 격리
- **CloudWatch/Monitoring** - 모니터링
