### 1단계: Azure CLI 버전 확인
```bash
az version
```

### 2단계: 올바른 명령어로 도메인 확인
```bash
# 방법 1: Microsoft Graph API 사용
az rest --method GET --uri "https://graph.microsoft.com/v1.0/domains" --headers "Content-Type=application/json"

# 방법 2: 현재 사용자 정보로 도메인 확인
az account show --query "user.name" -o tsv

# 방법 3: 테넌트 정보 확인
az account tenant list --output table
```

### 3단계: 간단한 방법으로 도메인 확인
현재 로그인된 사용자의 이메일 주소에서 도메인 부분을 추출할 수 있습니다:

```bash
# 현재 사용자의 도메인 추출
az account show --query "user.name" -o tsv | cut -d'@' -f2
```

## �� 환경 변수 파일 수정

실제 도메인이 확인되면, 환경 변수 파일을 수정하세요:

```bash
# 예시: 실제 도메인이 "company.onmicrosoft.com"인 경우
# 실습1_azure_finops.env 파일에서:
AZURE_DOMAIN="company.onmicrosoft.com"
```

## 🚀 대안 방법

만약 도메인 확인이 어렵다면, 임시로 다음과 같이 설정할 수도 있습니다:

```bash
# 환경 변수 파일에서 AZURE_DOMAIN을 주석 처리하고
# 직접 사용자 이메일 주소를 설정
# AZURE_DOMAIN="contoso.onmicrosoft.com"

# 사용자 설정을 직접 지정
FINANCE_USER="finance_user@your-actual-domain.com"
IT_ADMIN_USER="itadmin_user@your-actual-domain.com"
IT_ENGINEER_USER="engineer_user@your-actual-domain.com"
```

어떤 방법을 시도해보시겠습니까? Azure CLI 버전을 먼저 확인해보는 것이 좋겠습니다.
