**구성 설명:**
- **Azure AD (Entra ID)**: 사용자 및 역할 관리
  - Finance User: Cost Management Reader 역할
  - IT Admin: Contributor 역할  
  - IT Engineer: Storage Blob Data Contributor 역할
- **Management Group**: 조직 구조화 및 정책 적용
- **Resource Group**: 리소스 그룹화 및 태깅
- **Storage Account**: 데이터 저장 및 Blob 컨테이너
- **Policy**: 지역 제한 정책 (한국 리전만 허용)
- **Lock**: 리소스 삭제 방지
- **Cost Management**: 예산 설정 및 알림

**왜 이렇게 구성했는가:**
1. **최소 권한 원칙**: 각 사용자에게 필요한 최소 권한만 부여
2. **거버넌스**: 정책과 잠금을 통한 리소스 보호
3. **비용 관리**: 예산 설정과 알림을 통한 비용 통제
4. **확장성**: Management Group을 통한 조직 확장 가능

**구성 설명:**
- **Client Layer**: 다양한 클라이언트에서 API 접근
- **API Gateway**: REST API 엔드포인트 제공
- **Lambda Functions**: 서버리스 함수들
  - proposal-upload: 제안 업로드 처리
  - proposal-analysis: 제안 분석
  - notification: 알림 발송
- **Data Layer**:
  - DynamoDB: 제안 데이터 저장
  - S3: 문서 파일 저장
  - SNS: 알림 발송
- **Step Functions**: 워크플로우 오케스트레이션
- **Monitoring**: CloudWatch를 통한 모니터링

**왜 이렇게 구성했는가:**
1. **서버리스**: 인프라 관리 없이 확장 가능한 시스템
2. **마이크로서비스**: 각 기능을 독립적인 서비스로 분리
3. **이벤트 기반**: 비동기 처리로 성능 최적화
4. **자동화**: Step Functions를 통한 워크플로우 자동화
5. **모니터링**: 실시간 모니터링 및 알림
