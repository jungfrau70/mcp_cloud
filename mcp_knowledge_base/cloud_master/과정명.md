## 🛠️ 기술 스택

### 컨테이너 기술
- **Docker** - 컨테이너화 및 이미지 관리
- **Kubernetes** - 컨테이너 오케스트레이션
- **Helm** - 패키지 관리 및 배포
- **Istio** - 서비스 메시 및 트래픽 관리

### 클라우드 플랫폼
- **AWS EKS** - 관리형 Kubernetes 서비스
- **GCP GKE** - Google Kubernetes Engine
- **AWS ECS/Fargate** - 서버리스 컨테이너 실행
- **GCP Cloud Run** - 완전 관리형 서버리스 플랫폼

### DevOps 도구
- **GitHub Actions** - CI/CD 파이프라인
- **Terraform** - 인프라스트럭처 as Code
- **Prometheus + Grafana** - 모니터링 및 시각화
- **ELK Stack** - 로그 수집 및 분석
