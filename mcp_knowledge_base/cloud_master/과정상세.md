# 클라우드 실무력 강화! AWS & GCP 활용법(마스터)

## 📌 과정 개요

본 과정은 클라우드 기초 및 중급 과정을 수료한 학습자를 대상으로 AWS와 GCP의 **실무 전반을 아우르는 마스터 수준 과정**입니다. CI/CD 자동화, 컨테이너 배포, 고가용성 인프라, 비용 최적화 및 운영 등 **클라우드 실무 핵심 기술**을 통합적으로 학습하고 실습합니다.

* **교육일정**: 9/22(월) \~ 9/23(화) (2일, 총 14시간)
* **교육시간**: 9:00 \~ 17:00 (7시간/일)
* **교육방식**: 온라인: 실습 및 프로젝트 중심

---

## 📌 학습 목표

* Docker 및 GitHub Actions 기반 **완전 자동화된 배포 파이프라인** 구축
* AWS/GCP 환경에서 **컨테이너 서비스(ECS, GKE)** 운영
* **고가용성 및 Auto Scaling 아키텍처** 설계와 장애 복구 시뮬레이션
* 클라우드 비용 분석 도구(AWS Cost Explorer, GCP Billing Reports) 활용
* **팀 프로젝트 수행**을 통한 실전 아키텍처 설계 및 비용 최적화 전략 수립

---

## 📌 커리큘럼

### 📅 1일차: CI/CD와 VM 기반 컨테이너 배포 🚀

1. **Docker 기초 및 Dockerfile 최적화**

   * Dockerfile 작성 및 멀티스테이지 빌드
   * Docker Compose를 활용한 다중 서비스 관리
   * 실습: 웹 애플리케이션 Docker 이미지 빌드 및 최적화

2. **GitHub Actions CI/CD 파이프라인**

   * Workflow 작성 및 자동화된 빌드/배포 구현
   * 실습: Docker 이미지 자동 빌드 → Docker Hub 푸시

3. **VM 기반 컨테이너 배포**

   * AWS EC2 + Docker / GCP Compute Engine + Docker
   * 실습: Docker 컨테이너를 VM에 배포 및 관리

4. **완전 자동화된 VM 배포 파이프라인**

   * GitHub Actions + VM 배포 자동화
   * 실습: GitHub 푸시 → Docker 빌드 → VM 배포 자동화

---

### 📅 2일차: 로드 밸런싱 및 모니터링 ⚖️

1. **로드 밸런싱 및 Auto Scaling**

   * AWS ELB + Auto Scaling Group / GCP Cloud LB + Managed Instance Group
   * 실습: VM 기반 로드 밸런싱 환경 구성

2. **컨테이너 모니터링 및 로깅**

   * Docker 로그 관리 및 모니터링 도구 연동
   * 실습: Prometheus + Grafana 모니터링 구축

3. **장애 복구 및 운영 자동화**

   * Health Check 기반 자동 교체 및 복구
   * 실습: 장애 시뮬레이션 및 자동 복구 테스트

4. **비용 최적화 및 운영 전략**

   * VM 기반 아키텍처 비용 분석
   * 실습: 비용 최적화 전략 수립 및 발표
