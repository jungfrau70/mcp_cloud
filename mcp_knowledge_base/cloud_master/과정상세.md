## AWS/GCP 실전 마스터 과정 3일 교육 커리큘럼

다음은 초보자를 대상으로 한 클라우드 기초 교육에 이어, 인프라 설계부터 운영까지 아우르는 **'클라우드(AWS/GCP) 실전 마스터 과정'** 3일 교육 커리큘럼입니다. 이 커리큘럼은 GitHub Actions, Docker, Auto Scaling, 로드 밸런싱, 비용 분석 등 주요 내용을 포함하며, 이론과 실습을 병행하여 실무 역량을 강화하는 데 초점을 맞췄습니다.

---

### 📅 **1일차 (9/22, 월)**: **CI/CD와 컨테이너 기반 자동 배포 실습** 🚀

* **1교시 (9:00~10:30): 컨테이너 기술 및 Docker 심화**
    * 컨테이너 기반 아키텍처의 장점과 필요성
    * **Dockerfile** 작성법 및 효율적인 이미지 빌드 전략
    * Docker Compose를 활용한 다중 컨테이너 애플리케이션 관리
    * 실습: Dockerfile로 웹 애플리케이션 이미지 빌드 및 실행
* **2교시 (10:30~12:00): GitHub Actions를 활용한 CI/CD 파이프라인 구축**
    * CI/CD(지속적 통합/지속적 배포)의 개념과 중요성
    * GitHub Actions 기본 문법 및 워크플로우(Workflow) 이해
    * 실습: GitHub 저장소에 코드를 푸시하면 자동으로 Docker 이미지를 빌드하고 레지스트리에 푸시하는 파이프라인 구축
* **3교시 (13:00~14:30): 클라우드 환경에 컨테이너 배포**
    * **AWS ECS(Elastic Container Service)** 또는 **GCP GKE(Google Kubernetes Engine)** 소개 및 아키텍처
    * AWS ECS Fargate와 EC2의 차이점 및 장단점 비교
    * 실습: 빌드된 Docker 이미지를 AWS ECS/GCP GKE에 배포하고 서비스 확인
* **4교시 (14:30~17:00): 자동 배포 파이프라인 완성**
    * GitHub Actions 워크플로우에 클라우드 배포 단계 추가
    * 실습: 코드를 GitHub에 푸시하면 자동으로 Docker 이미지 빌드, 컨테이너 레지스트리 푸시, AWS/GCP에 배포까지 완료되는 완벽한 **자동 배포 파이프라인** 구축 및 검증

---

### 📅 **2일차 (9/23, 화)**: **고가용성 및 로드 밸런싱 실무** ⚖️

* **1교시 (9:00~10:30): 가용성 확보를 위한 인프라 설계**
    * **고가용성(High Availability)**의 개념과 필요성
    * **로드 밸런싱(Load Balancing)**의 종류 (L4, L7) 및 동작 원리
    * AWS의 **ELB(Elastic Load Balancing)**와 GCP의 **Cloud Load Balancing** 서비스 특징
* **2교시 (10:30~12:00): Auto Scaling 그룹 구성 및 실습**
    * **Auto Scaling**의 개념 및 지표 기반/예약 기반 확장/축소 전략
    * AWS EC2 Auto Scaling Group과 GCP Managed Instance Group(MIG) 구성
    * 실습: CPU 사용률 기반으로 인스턴스가 자동으로 확장/축소되도록 Auto Scaling 그룹 설정
* **3교시 (13:00~14:30): 로드 밸런싱과 Auto Scaling 연동 실습**
    * 로드 밸런서 뒤에 Auto Scaling 그룹 연결하기
    * 상태 점검(Health Check)을 통한 비정상 인스턴스 자동 교체
    * 실습: 로드 밸런서와 Auto Scaling 그룹을 결합하여 트래픽 증가에 따라 자동으로 인스턴스가 추가되는 **고가용성 아키텍처** 구성
* **4교시 (14:30~17:00): 장애 시뮬레이션 및 복구 훈련**
    * 인프라 구성 후 인위적인 장애(인스턴스 강제 종료 등) 발생시키기
    * **Auto Scaling** 및 **Health Check**를 통한 자동 복구 과정 확인
    * Q&A 및 복습

---

### 📅 **3일차 (9/24, 수)**: **클라우드 비용 최적화 및 운영** 💰

* **1교시 (9:00~10:30): 클라우드 비용 분석 및 절감 전략**
    * 클라우드 과금 모델(온디맨드, 예약 인스턴스, 스팟 인스턴스) 이해
    * 비용 분석 도구: AWS Cost Explorer, GCP Billing Reports 활용법
    * **비용 절감 핵심 원칙**: 사용하지 않는 리소스 삭제, 예약 인스턴스/Savings Plan 활용, 스팟 인스턴스 활용
* **2교시 (10:30~12:00): 운영 및 모니터링 심화**
    * **AWS CloudWatch** 및 **GCP Cloud Monitoring**을 활용한 모니터링 시스템 구축
    * 경보(Alarm) 설정 및 이벤트 기반 자동화
    * 로그 관리: AWS CloudTrail, GCP Cloud Logging을 통한 인프라 변경 이력 추적
* **3교시 (13:00~14:30): 비용 절감 사례 기반 전략 수립**
    * 실제 클라우드 비용 절감 성공 및 실패 사례 분석
    * **팀 프로젝트:** 가상의 서비스 시나리오에 맞는 클라우드 인프라 아키텍처 설계
    * 예상 비용 계산 및 비용 최적화 전략 발표 준비
* **4교시 (14:30~17:00): 최종 프로젝트 발표 및 피드백**
    * 팀별로 설계한 **인프라 아키텍처** 및 **비용 절감 전략** 발표
    * 강사 및 수강생 간의 피드백 및 토론
    * 교육 마무리 및 수료증 전달
