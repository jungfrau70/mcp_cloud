# 클라우드 실무력 강화! AWS & GCP 활용법(마스터)

## 📌 과정 개요

본 과정은 클라우드 기초 및 중급 과정을 수료한 학습자를 대상으로 AWS와 GCP의 **실무 전반을 아우르는 마스터 수준 과정**입니다. CI/CD 자동화, 컨테이너 배포, 고가용성 인프라, 비용 최적화 및 운영 등 **클라우드 실무 핵심 기술**을 통합적으로 학습하고 실습합니다.

* **교육일정**: 9/22(월) \~ 9/24(수) (3일, 총 21시간)
* **교육시간**: 9:00 \~ 17:00 (7시간/일)
* **교육방식**: 오프라인 실습 및 프로젝트 중심

---

## 📌 학습 목표

* Docker 및 GitHub Actions 기반 **완전 자동화된 배포 파이프라인** 구축
* AWS/GCP 환경에서 **컨테이너 서비스(ECS, GKE)** 운영
* **고가용성 및 Auto Scaling 아키텍처** 설계와 장애 복구 시뮬레이션
* 클라우드 비용 분석 도구(AWS Cost Explorer, GCP Billing Reports) 활용
* **팀 프로젝트 수행**을 통한 실전 아키텍처 설계 및 비용 최적화 전략 수립

---

## 📌 커리큘럼

### 📅 1일차: CI/CD와 컨테이너 기반 자동 배포 🚀

1. **컨테이너 기술 심화**

   * Dockerfile 최적화 및 다중 컨테이너 관리(Docker Compose)
   * 실습: 웹 애플리케이션 Docker 이미지 빌드 및 실행
2. **GitHub Actions CI/CD 파이프라인**

   * Workflow 작성 및 자동화된 빌드/배포 구현
   * 실습: Docker 이미지 자동 빌드 → 레지스트리 푸시
3. **클라우드 컨테이너 배포**

   * AWS ECS(Fargate) vs GCP GKE 아키텍처 비교
   * 실습: Docker 이미지를 클라우드 환경에 배포
4. **완전 자동화된 배포 파이프라인**

   * GitHub Actions + 클라우드 배포 단계 통합
   * 실습: GitHub 푸시 → Docker 빌드 → 클라우드 배포 자동화

---

### 📅 2일차: 고가용성 및 로드 밸런싱 ⚖️

1. **고가용성 아키텍처 설계**

   * 로드 밸런싱(L4/L7) 원리 및 서비스(AWS ELB, GCP Cloud LB)
   * 실습: 로드 밸런싱 환경 구성
2. **Auto Scaling 그룹 구성**

   * AWS Auto Scaling Group / GCP Managed Instance Group
   * 실습: CPU 지표 기반 자동 확장/축소 구성
3. **로드 밸런싱 + Auto Scaling 연동**

   * Health Check 기반 장애 탐지 및 자동 교체
   * 실습: 트래픽 증가에 따라 자동 확장되는 아키텍처 구현
4. **장애 시뮬레이션 및 복구 훈련**

   * 인위적 장애 발생 및 복구 확인
   * 실습: Auto Scaling + Health Check 통한 무중단 복구

---

### 📅 3일차: 비용 최적화 및 운영 💰

1. **클라우드 비용 분석 및 절감 전략**

   * 온디맨드, 예약 인스턴스, 스팟 인스턴스 비교
   * 실습: AWS Cost Explorer, GCP Billing Reports 활용
2. **운영 및 모니터링 심화**

   * AWS CloudWatch, GCP Cloud Monitoring & Logging
   * 실습: 알람, 이벤트 기반 자동화, 변경 이력 추적
3. **비용 최적화 프로젝트 설계**

   * 실제 비용 절감 사례 분석
   * 팀 프로젝트: 가상의 서비스 아키텍처 설계 및 비용 절감 전략 수립
4. **최종 발표 및 피드백**

   * 팀별 인프라 아키텍처 및 최적화 전략 발표
   * 피드백 및 토론, 교육 마무리
