WSL(Windows Subsystem for Linux)는 Windows에서 리눅스 환경을 실행할 수 있게 해주는 도구입니다. WSL을 설치하고 구성하는 방법은 다음과 같습니다.

### 1. WSL 설치

1. **Windows 기능 켜기**

   * 시작 메뉴에서 \*\*"Windows 기능 켜기/끄기"\*\*를 검색하여 엽니다.
   * 목록에서 \*\*"Windows Subsystem for Linux"\*\*와 \*\*"가상 머신 플랫폼"\*\*을 체크합니다.

     * 이 두 기능은 WSL2를 사용하기 위해 필수입니다.
   * \*\*"확인"\*\*을 클릭한 후, 시스템이 요구하는 경우 재부팅합니다.

2. **Windows 업데이트 확인**

   * WSL2는 Windows 10 버전 1903 이상에서 지원되므로, 시스템 업데이트가 필요한 경우 최신 버전으로 업데이트합니다.

3. **WSL 2 설치 및 설정**

   * PowerShell을 **관리자 권한**으로 실행하고 다음 명령어를 입력합니다:

     ```powershell
     wsl --set-default-version 2
     ```
   * 이 명령어는 WSL2를 기본으로 설정합니다.

4. **Linux 배포판 설치**

   * Microsoft Store를 열고 원하는 리눅스 배포판을 검색하여 설치합니다. 예를 들어, **Ubuntu**, **Debian**, **Kali Linux** 등이 있습니다.
   * 배포판을 선택하고 **설치** 버튼을 클릭합니다.

5. **리눅스 배포판 초기화**

   * 설치가 완료되면 **시작 메뉴**에서 설치한 배포판을 실행합니다. 첫 실행 시, 리눅스 환경을 설정하고 사용자 계정 및 비밀번호를 설정해야 합니다.

### 2. WSL 구성

1. **기본 배포판 변경 (옵션)**

   * 여러 개의 배포판을 설치한 경우, 기본 배포판을 변경할 수 있습니다. 아래 명령어를 통해 기본 배포판을 설정할 수 있습니다:

     ```powershell
     wsl --setdefault <배포판 이름>
     ```

2. **WSL 2 사용 여부 확인**

   * WSL 2로 잘 설정되었는지 확인하려면 다음 명령어를 입력합니다:

     ```powershell
     wsl --list --verbose
     ```

     * 이 명령어는 각 배포판의 버전(WSL 1 또는 WSL 2)을 보여줍니다.

3. **리눅스와 윈도우 파일 시스템 간 접근**

   * WSL에서는 윈도우 파일 시스템에 접근할 수 있으며, 반대로 리눅스 파일 시스템에도 윈도우에서 접근할 수 있습니다.
   * 윈도우 파일 시스템은 `/mnt/c/`, `/mnt/d/`와 같은 경로로 접근 가능합니다.
   * 리눅스 파일 시스템은 `\\wsl$`를 통해 윈도우 탐색기에서 접근할 수 있습니다.

### 3. 기타 설정 (선택 사항)

* **리눅스 소프트웨어 설치**: 리눅스 환경에서 기본적인 패키지 관리자를 사용하여 필요한 소프트웨어를 설치할 수 있습니다. 예를 들어, `apt`를 사용하여 패키지를 설치할 수 있습니다:

  ```bash
  sudo apt update
  sudo apt install <패키지 이름>
  ```

* **X 서버 사용**: GUI 애플리케이션을 실행하려면 X 서버를 설치해야 합니다. `VcXsrv`나 `Xming`을 사용할 수 있습니다. 이후 X 서버를 실행한 후 `DISPLAY` 환경 변수를 설정해야 합니다.

  예시 (Ubuntu):

  ```bash
  export DISPLAY=:0
  ```

---

이렇게 WSL을 설치하고 기본적인 구성을 마친 후, 리눅스 환경을 Windows에서 직접 사용할 수 있습니다. 혹시 더 구체적인 설정이 필요하다면 어떤 부분이 필요한지 말씀해 주세요!
