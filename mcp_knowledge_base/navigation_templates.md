## 📋 적용 가이드라인

### 1. 상단 링크 적용
- 모든 문서의 링크 바로 아래에 상단 네비게이션 추가
- 기존 복잡한 링크 구조 제거
- 3단계 계층 구조로 통일

### 2. 하단 링크 적용
- 문서 끝에 하단 네비게이션 추가
- 상단과 동일한 구조 + 관련 과정 링크
- 기존 하단 링크 구조 대체

### 3. 일관성 유지
- 모든 문서가 동일한 템플릿 사용
- 링크 경로 정확성 확인
- 이모지와 텍스트 일관성 유지

### 4. 검증 체크리스트
