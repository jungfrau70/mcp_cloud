3. 두번째/세번째 이미지: 커리큘럼에서 문서를 읽고 있다가 지식베이스로 화면전환 시, 읽어 보여 줘야 하는데 인코딩 문제인지 아니면 경로 문제인지 보여주지 못하고 있음. 그리고, 해당 문서가 없거나 열지 못하는 경우 Markdown 탭 아닌 FileTree 를 보여주었으면 좋겠음.
4. 네번째 이미지: 지식베이스 FileTree 텝 상단에 있는 커리큘럼 설정 버튼으로 팝업되는 모달에서 선택한 디렉토리가 어디에 저장하는지 모르겠고, 또한 여기서 설정한 디렉토리를 ContentView 에서 보여주기로 되어 있는데 이 또한 어느 파일을 보고 읽어 보여 주는지 확인이 안됨. 여하튼 문제 해결 필요
5. 커리큘럼 ContentView 에서 ppt, pptx, pdf, markdown 문서를 선택하면 메인 화면에 보여줘야 하는데, 오류가 발생되고 있어.

   4. 그리고, 모든 서브실행모듈을 cloud_intermediate/repo/tools/cloud/ 디렉토리에 위치한다.
