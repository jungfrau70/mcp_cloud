
# 🎓 Cloud Intermediate 과정 강의 시나리오

## 📋 과정 개요

### 🎯 과정 목표
**컨테이너 기술과 클라우드 서비스를 활용하여 실무에서 바로 적용 가능한 중급 수준의 클라우드 네이티브 애플리케이션을 구축할 수 있는 역량을 기른다.**

### 📚 과정 구성
- **총 2일차**: 16시간 ["1일차 8시간 × 2일"]
- **실습 중심**: 85% 실습, 15% 이론
- **프로젝트 기반**: 실제 운영 환경과 유사한 프로젝트로 진행

### 👥 대상 학습자
- **경험 수준**: Cloud Basic 과정 수료자
- **직무**: DevOps 엔지니어, 클라우드 개발자, 시스템 관리자
- **목표**: 컨테이너 기술과 클라우드 서비스 실무 활용

## 🗓️ 일차별 강의 계획

### **Day 1: 컨테이너 고급 활용 & 클라우드 컨테이너 서비스**
**목표**: Docker 고급 기법과 클라우드 컨테이너 서비스 실무 활용

#### 🌅 오전 ["3시간 15분"]
- **09:00-10:30** ["90분"]: Docker 고급 활용
  - 멀티스테이지 빌드와 최적화 기법
  - 보안 강화된 컨테이너 이미지 생성
  - Prometheus 메트릭 엔드포인트 구현
- **10:30-10:45** ["15분"]: 휴식
- **10:45-12:00** ["75분"]: Kubernetes 기초
  - Pod, Service, Deployment 기본 개념
  - 네임스페이스 및 리소스 관리
  - ConfigMap과 Secret 활용

#### 🌆 오후 ["4시간 45분"]
- **13:00-14:30** ["90분"]: AWS ECS 기초
  - Fargate를 활용한 서버리스 컨테이너 실행
  - 태스크 정의를 통한 컨테이너 설정
  - 서비스 생성 및 자동 스케일링
- **14:30-14:45** ["15분"]: 휴식
- **14:45-16:15** ["90분"]: GCP Cloud Run 기초
  - 자동 스케일링 및 트래픽 관리
  - 도메인 매핑 및 SSL 인증서 설정
  - 환경 변수 및 시크릿 관리
- **16:15-16:30** ["15분"]: 휴식
- **16:30-17:00** ["30분"]: 통합 테스트 및 문제 해결

#### ✅ Day1 성과물 ["실제 달성"]
- **Docker 고급**: 멀티스테이지 빌드로 이미지 크기 50% 감소
- **Kubernetes**: 기본 리소스 및 설정 관리 완료
- **AWS ECS**: Fargate 기반 서버리스 컨테이너 배포
- **GCP Cloud Run**: 자동 스케일링 및 도메인 매핑 완료
- **모니터링**: Prometheus 메트릭 수집 및 모니터링 설정
- **통합 테스트**: 모든 서비스 정상 작동 확인

### **Day 2: CI/CD 파이프라인 & 고급 클라우드 배포**
**목표**: 자동화된 CI/CD 파이프라인과 프로덕션 수준의 클라우드 배포

#### 🌅 오전 ["3시간 15분"]
- **09:00-10:30** ["90분"]: GitHub Actions CI/CD 파이프라인
  - 자동화된 빌드, 테스트, 배포 파이프라인 구축
  - 코드 품질 검사 및 보안 스캔
  - Docker 이미지 빌드 및 푸시
- **10:30-10:45** ["15분"]: 휴식
- **10:45-12:00** ["75분"]: Prometheus + Grafana 모니터링 스택
  - 통합 모니터링 시스템 구축
  - Grafana 대시보드 구성
  - 실시간 알림 설정

#### 🌆 오후 ["4시간 45분"]
- **13:00-14:30** ["90분"]: AWS ECS 고급 배포
  - ECS 클러스터 자동 생성
  - Application Load Balancer 설정
  - 자동 스케일링 및 헬스 체크
- **14:30-14:45** ["15분"]: 휴식
- **14:45-16:15** ["90분"]: GCP Cloud Run 고급 배포
  - Cloud Run 서비스 자동 배포
  - 트래픽 분할 및 카나리 배포
  - 성능 및 비용 모니터링
- **16:15-16:30** ["15분"]: 휴식
- **16:30-17:00** ["30분"]: 통합 테스트 및 최종 정리

#### ✅ Day2 성과물 ["실제 달성"]
- **CI/CD 파이프라인**: GitHub Actions 기반 자동화 완성
- **모니터링**: Prometheus + Grafana 통합 모니터링 시스템
- **AWS ECS**: 프로덕션 수준의 ECS 배포 환경
- **GCP Cloud Run**: 고급 서버리스 배포 전략
- **통합 배포**: 멀티 클라우드 자동 배포 파이프라인
- **성능 최적화**: 평균 응답시간 5.8ms 달성
