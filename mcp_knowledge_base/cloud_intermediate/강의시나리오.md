
# Cloud Intermediate 강의 시나리오

> 📋 **과정명**: 클라우드 실무력 강화! AWS & GCP 활용법(중급)  
> 📋 **기간**: 2일 (2024년 10월 1일~2일)  
> 📋 **참고 코드**: https://github.com/jungfrau70/cloud-intermediate.git  
> 📋 **실습 환경**: WSL2 + Docker + AWS/GCP 계정

---

## 🎯 전체 과정 개요

### **과정 목표**
- **컨테이너 기술**: Docker 고급 활용 및 Kubernetes 기초
- **클라우드 서비스**: AWS ECS, GCP Cloud Run 실무 활용
- **CI/CD 파이프라인**: GitHub Actions를 통한 자동화된 배포
- **모니터링**: Prometheus + Grafana 통합 모니터링 시스템
- **실무 중심**: 프로덕션 환경에서 바로 활용 가능한 기술

### **학습자 대상**
- Cloud Basic 과정 완료자
- DevOps 엔지니어, 클라우드 개발자
- 시스템 관리자, 인프라 엔지니어
- 컨테이너 기술을 실무에 적용하고자 하는 개발자

## 📅 Day 1: 컨테이너 및 Kubernetes 기초

### **🌅 오전 (4시간) - 컨테이너 기초**

#### **1교시: Docker 고급 활용 (90분)**
**목표**: 멀티스테이지 빌드와 최적화 기법 학습

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 Docker 고급 실습**
   ```bash
   cd mcp_knowledge_base/cloud_intermediate/repo/scripts
   ./cloud-intermediate-helper.sh docker-practice
   ```

2. **멀티스테이지 빌드 실습**
   - 기존 Dockerfile과 최적화된 Dockerfile 비교
   - 이미지 크기 50% 이상 감소 확인
   - 보안 강화된 컨테이너 이미지 생성

3. **Prometheus 메트릭 엔드포인트 구현**
   - Node.js 애플리케이션에 메트릭 엔드포인트 추가
   - 실시간 메모리, CPU 사용량 모니터링

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day1/docker-advanced/`
- 자동화 스크립트: `repo/scripts/day1-practice.sh`

#### **2교시: Kubernetes 기초 (90분)**
**목표**: Pod, Service, Deployment 기본 개념 학습

**실습 시나리오**:
1. **Kubernetes 기본 리소스 실습**
   ```bash
   ./cloud-intermediate-helper.sh kubernetes-practice
   ```

2. **네임스페이스 및 리소스 관리**
   - 네임스페이스 생성 및 관리
   - ResourceQuota와 LimitRange 설정
   - 리소스 격리 및 관리

3. **ConfigMap과 Secret 활용**
   - 애플리케이션 설정 외부화
   - 민감한 정보 보안 관리
   - 환경별 설정 관리

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day1/kubernetes-basics/`
- YAML 파일: nginx-deployment.yaml, configmap-secret.yaml, namespace.yaml

### **🌆 오후 (4시간) - 클라우드 컨테이너 서비스**

#### **3교시: AWS ECS 기초 (90분)**
**목표**: AWS ECS를 활용한 컨테이너 서비스 배포

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 AWS ECS 배포**
   ```bash
   ./cloud-intermediate-helper.sh cloud-services-practice
   ```

2. **ECS 클러스터 생성 및 관리**
   - Fargate를 활용한 서버리스 컨테이너 실행
   - 태스크 정의를 통한 컨테이너 설정
   - 서비스 생성 및 자동 스케일링

3. **모니터링 스택에서 ECS 모니터링**
   - CloudWatch 로그 수집 설정
   - ECS 메트릭 모니터링
   - 헬스 체크 및 알림 설정

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day1/cloud-container-services/aws-ecs-task-definition.json`

#### **4교시: GCP Cloud Run 기초 (90분)**
**목표**: GCP Cloud Run을 활용한 서버리스 컨테이너 배포

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 GCP Cloud Run 배포**
   ```bash
   ./cloud-intermediate-helper.sh cloud-services-practice
   ```

2. **Cloud Run 서비스 생성 및 배포**
   - 자동 스케일링 및 트래픽 관리
   - 도메인 매핑 및 SSL 인증서 설정
   - 환경 변수 및 시크릿 관리

3. **모니터링 스택에서 Cloud Run 모니터링**
   - Cloud Monitoring 메트릭 수집
   - 로그 기반 모니터링 설정
   - 성능 및 비용 모니터링

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day1/cloud-container-services/gcp-cloud-run.yaml`

## 📅 Day 2: CI/CD, 클라우드 배포 및 모니터링

### **🌅 오전 (4시간) - CI/CD 및 모니터링**

#### **1교시: GitHub Actions CI/CD 파이프라인 (90분)**
**목표**: 자동화된 빌드, 테스트, 배포 파이프라인 구축

**실습 시나리오**:
1. **GitHub Actions 워크플로우 작성**
   ```bash
   ./cloud-intermediate-helper.sh cicd-practice
   ```

2. **자동화된 CI/CD 파이프라인 구축**
   - 코드 품질 검사 (ESLint, 테스트)
   - 보안 스캔 (Trivy)
   - Docker 이미지 빌드 및 푸시
   - 환경별 자동 배포

3. **모니터링 스택에서 CI/CD 모니터링**
   - 빌드 성공률 모니터링
   - 배포 시간 및 성공률 추적
   - 알림 및 대시보드 설정

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day2/cicd-pipeline/`
- 자동화 스크립트: `repo/scripts/day2-practice.sh`

#### **2교시: Prometheus + Grafana 모니터링 스택 (90분)**
**목표**: 통합 모니터링 시스템 구축 및 활용

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 모니터링 스택 기동**
   ```bash
   ./cloud-intermediate-helper.sh monitoring-practice
   ```

2. **Prometheus + Grafana 스택 구축**
   - Prometheus 메트릭 수집 설정
   - Grafana 대시보드 구성
   - Node Exporter를 통한 시스템 메트릭 수집

3. **모니터링 스택에서 app 배포 시 모니터링 구성**
   - 애플리케이션 메트릭 수집
   - 실시간 알림 설정
   - 성능 및 가용성 모니터링

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day2/monitoring-basics/`
- 자동화 스크립트: `repo/scripts/monitoring-stack.sh`

### **🌆 오후 (4시간) - 클라우드 배포 및 통합**

#### **3교시: AWS ECS 고급 배포 (90분)**
**목표**: AWS ECS를 활용한 프로덕션 배포 전략

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 AWS에 app 운영을 위한 VM 배포**
   ```bash
   ./cloud-intermediate-helper.sh cloud-deployment-practice
   ```

   - ECS 클러스터 자동 생성
   - Application Load Balancer 설정
   - 자동 스케일링 및 헬스 체크

3. **모니터링 스택에서 모니터링 할 수 있게 구성 및 설정**
   - ECS 메트릭을 Prometheus로 수집
   - Grafana 대시보드에서 ECS 상태 모니터링
   - 알림 및 로그 분석 설정

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day2/cloud-deployment/aws-ecs-deploy.sh`

#### **4교시: GCP Cloud Run 고급 배포 (90분)**
**목표**: GCP Cloud Run을 활용한 서버리스 배포 전략

**실습 시나리오**:
1. **WSL 환경에서 helper 함수 사용하여 GCP에 app 운영을 위한 VM 배포**
   ```bash
   ./cloud-intermediate-helper.sh cloud-deployment-practice
   ```

2. **GitHub Actions CI/CD 사용하여 GCP에 app 배포**
   - Cloud Run 서비스 자동 배포
   - 도메인 매핑 및 SSL 인증서 설정
   - 트래픽 분할 및 카나리 배포

3. **모니터링 스택에서 모니터링 할 수 있게 구성 및 설정**
   - Cloud Run 메트릭을 Prometheus로 수집

   - 성능 및 비용 모니터링 설정

**실습 코드 위치**:
- 샘플 코드: `repo/samples/day2/cloud-deployment/gcp-cloud-run-deploy.sh`

## 🚨 문제 해결 가이드

### **환경 관련 문제**
```bash
# WSL 환경 체크
wsl --status
docker --version
docker-compose --version

# 클라우드 계정 체크
aws sts get-caller-identity
gcloud auth list
```

### **모니터링 스택 문제**
```bash
# 모니터링 스택 재시작
./monitoring-stack.sh cleanup
./monitoring-stack.sh setup

# 서비스 상태 확인
./monitoring-stack.sh status
```

### **배포 관련 문제**
```bash
# AWS ECS 문제 해결
aws ecs describe-services --cluster your-cluster --services your-service

# GCP Cloud Run 문제 해결
gcloud run services describe your-service --region your-region
```
