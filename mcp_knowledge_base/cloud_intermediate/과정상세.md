# 클라우드 실무력 강화! AWS & GCP 활용법(중급)

## 📌 과정 개요

본 과정은 클라우드 기초 과정을 수료한 학습자를 대상으로 AWS와 GCP의 **중급 실무 기술**을 학습하고 실습하는 과정입니다. 컨테이너, CI/CD 파이프라인, 고가용성 아키텍처, 모니터링 및 최적화 등 **실무 환경에서 즉시 활용 가능한 기술**에 집중합니다.

* **교육일정**: 10/1(수) \~ 10/2(목) (2일, 총 14시간)
* **교육시간**: 9:00 \~ 17:00 (7시간/일)
* **교육방식**: 오프라인 실습 중심

## 📌 학습 목표

* Docker 컨테이너 기술의 심화 활용 및 최적화
* GitHub Actions 기반 **CI/CD 파이프라인 완전 자동화** 구현
* AWS/GCP **고가용성 및 확장성 아키텍처 설계**
* 클라우드 **모니터링 및 로깅 시스템** 구축
* **실무 프로젝트 수행**을 통한 종합적인 클라우드 역량 강화

---

## 📌 커리큘럼

### 📅 1일차: 컨테이너 및 CI/CD 파이프라인 🚀

1. **컨테이너 기술 심화**

   * Dockerfile 최적화 및 멀티스테이지 빌드
   * Docker Compose를 활용한 다중 서비스 관리
   * 실습: 효율적인 Dockerfile 작성 및 최적화
2. **GitHub Actions CI/CD 파이프라인**

   * 고급 워크플로우 작성법
   * 자동화된 테스트, 빌드, 배포 파이프라인 구축
   * 실습: GitHub Actions로 CI/CD 파이프라인 구현
3. **클라우드 컨테이너 서비스**

   * AWS ECS (Fargate) 심화 / GCP Cloud Run 및 GKE 소개
   * 컨테이너 오케스트레이션 이해
   * 실습: 서버리스 컨테이너 배포(ECS, Cloud Run)
4. **완전 자동화된 배포 파이프라인**

   * GitHub Actions + 클라우드 연동
   * 환경별 배포 전략 (Staging, Production)
   * 실습: Blue-Green 배포 및 롤백 전략

---

### 📅 2일차: 고가용성 및 확장성 아키텍처 ⚖️

1. **고가용성 아키텍처 설계**

   * AWS Multi-AZ / GCP Multi-Region
   * 장애 복구 및 재해 복구 전략(DR)
   * 실습: Multi-AZ RDS 및 EC2 구성, GCP Multi-Region 배포
2. **로드 밸런싱 및 Auto Scaling**

   * AWS ELB 심화 / GCP Cloud Load Balancing
   * Auto Scaling 정책 및 메트릭 기반 확장
   * 실습: Auto Scaling + Load Balancer 연동
3. **모니터링 및 로깅 시스템**

   * AWS CloudWatch / GCP Monitoring & Logging
   * 경보 및 이벤트 기반 자동화
   * 실습: 커스텀 메트릭 대시보드 및 로그 기반 알림 구축
4. **종합 프로젝트 및 최적화**

   * 고가용성 웹 서비스 아키텍처 설계
   * 성능 최적화 및 비용 효율성 분석
   * 실습: 실제 서비스 시나리오 아키텍처 구현 및 발표
