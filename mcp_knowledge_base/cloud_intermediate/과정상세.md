# 📋 Cloud Intermediate - 과정 상세 정보

## 🎯 과정 개요

### **과정명**
**Cloud Intermediate - 클라우드 실무력 강화! AWS & GCP 활용법 (중급)**

### **과정 분류**
- **레벨**: 중급 (Intermediate)
- **분야**: 클라우드 컴퓨팅, DevOps, 컨테이너 기술
- **대상**: Cloud Basic 과정 수료자 또는 동등한 수준의 학습자

- **교육 방식**: 100% 자동화 실습 중심

## 🛠️ 실습 환경 상세

### **권장 환경**
- **AWS EC2**: t3.medium (2vCPU, 4GB RAM)
- **GCP GKE**: e2-medium 노드 3개
- **로컬 환경**: WSL2 또는 macOS/Linux

### **필수 도구**
- **Docker**: 컨테이너 실행 환경
- **Docker Compose**: 멀티 컨테이너 관리
- **kubectl**: Kubernetes 클러스터 관리
- **AWS CLI**: AWS 서비스 관리
- **GCP CLI**: GCP 서비스 관리
- **Git**: 버전 관리
- **GitHub**: 코드 저장소 및 CI/CD


## 🚀 자동화 기능 상세

### **자동화 스크립트**
- **환경 설정**: 자동으로 필요한 도구 설치 및 설정
- **실습 실행**: 단계별 실습 자동화
- **진행 모니터링**: 실시간 진행 상황 추적
- **리소스 정리**: 실습 후 자동 리소스 정리

### **실시간 모니터링**
- **강의 진행 대시보드**: 실시간 진행 상황 시각화
- **자동화 스크립트 모니터링**: 스크립트 실행 상태 추적
- **리소스 사용량 모니터링**: 클라우드 리소스 사용량 추적

### **Parameter 모드**
- **Interactive 모드**: 사용자 입력을 통한 단계별 진행
- **Parameter 모드**: 미리 정의된 파라미터로 자동 실행
- **테스트 모드**: 실습 환경 검증 및 테스트
