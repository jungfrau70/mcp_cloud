# 📚 클라우드 중급 과정 통합 강의 시나리오

## 🎯 통합 학습 목표

### 핵심 역량
- **Docker 고급 활용**: 멀티스테이지 빌드, 이미지 최적화 기법을 이해하고 적용합니다.
- **Kubernetes 기초**: Pod, Service, Deployment, ConfigMap, Secret 등 Kubernetes 핵심 리소스를 이해하고 관리합니다.
- **클라우드 컨테이너 서비스**: AWS ECS, GCP Cloud Run, AWS EKS, GCP GKE를 활용하여 다양한 클라우드 환경에 컨테이너 애플리케이션을 배포하고 운영합니다.
- **CI/CD 파이프라인**: GitHub Actions를 사용하여 코드 변경 시 자동으로 빌드, 테스트, 배포되는 CI/CD 파이프라인을 설계하고 구현합니다.
- **통합 모니터링**: Prometheus와 Grafana를 기반으로 AWS와 GCP 환경의 인프라, 플랫폼, 애플리케이션을 통합 모니터링하는 시스템을 구축합니다.
- **DevOps 실무**: 실제 운영 환경에서 요구되는 자동화, 모니터링, 배포 전략 등 DevOps 핵심 역량을 습득하고 실무에 적용합니다.

### 자동화 특징
- **🤖 100% 자동화**: 모든 실습이 자동화 스크립트로 완주 가능
- **📊 실시간 모니터링**: 강의 진행 상황 실시간 추적
- **🔄 Interactive & Parameter 모드**: 사용자 편의성 극대화
- **🧹 자동 리소스 정리**: 실습 후 깔끔한 환경 복원

## 📚 Day 1: 컨테이너 기초 및 클라우드 컨테이너 서비스

### **🎯 Day 1 학습 목표**
- Docker 고급 활용 (멀티스테이지 빌드, 최적화)
- Kubernetes 기초 (Pod, Service, Deployment)
- 클라우드 컨테이너 서비스 (AWS ECS, GCP Cloud Run)
- 통합 모니터링 허브 구축

### **🤖 자동화 실행**
```bash
# Day 1 전체 자동화 실행
./day1-practice.sh --action all

# 실시간 진행 상황 모니터링
./lecture-monitor.sh --monitor
```

### **📋 Day 1 실습 구성**

#### 1교시: Docker 고급 활용 (90분)
- **멀티스테이지 빌드**: 경량화된 이미지 생성
- **이미지 최적화**: 레이어 최적화 및 보안 강화
- **Docker Compose 고급 활용**: 복잡한 애플리케이션 스택 관리

#### 2교시: Kubernetes 기초 (90분)
- **Pod, Service, Deployment 생성**: Kubernetes 핵심 리소스 이해
- **ConfigMap, Secret 관리**: 설정 및 보안 정보 관리
- **로컬 Kubernetes 환경 구축**: 개발 환경 설정

#### 3교시: 클라우드 컨테이너 서비스 (90분)
- **AWS ECS 태스크 정의 및 서비스 생성**: AWS 컨테이너 서비스 활용
- **GCP Cloud Run 서비스 배포**: GCP 서버리스 컨테이너 서비스 활용
- **클라우드 네이티브 패턴 학습**: 클라우드 환경에 최적화된 배포 전략

#### 4교시: 통합 모니터링 허브 구축 (90분)
- **Prometheus + Grafana 스택**: 모니터링 인프라 구축
- **Node Exporter, Push Gateway**: 메트릭 수집 및 전송
- **AlertManager 설정**: 알림 시스템 구성

## 📚 Day 2: CI/CD 및 고급 클라우드 배포, 멀티 클라우드 모니터링

### **🎯 Day 2 학습 목표**
- CI/CD 파이프라인 구축 (GitHub Actions)
- 클라우드 고급 배포 전략
- 멀티 클라우드 통합 모니터링
- 실무 수준의 DevOps 자동화

### **🤖 자동화 실행**
```bash
# Day 2 전체 자동화 실행
./day2-practice.sh --action all

# 실시간 진행 상황 모니터링
./lecture-monitor.sh --monitor
```

### **📋 Day 2 실습 구성**

#### 1교시: GitHub Actions CI/CD 파이프라인 (90분)
- **GitHub Actions 워크플로우**: 자동화된 빌드, 테스트, 배포 파이프라인
- **자동화된 테스트 및 배포**: 품질 보장 및 배포 자동화
- **환경별 배포 전략**: 개발, 스테이징, 프로덕션 환경 관리

#### 2교시: 멀티 클라우드 통합 모니터링 시스템 (90분)
- **AWS EKS 클러스터 모니터링**: Infrastructure/Platform 모니터링
- **GCP GKE 클러스터 모니터링**: 멀티 클라우드 통합 모니터링
- **Global Dashboard**: 통합 시각화 및 알림 시스템

#### 3교시: AWS Application 모니터링 (90분)
- **GitHub Actions를 통한 AWS EKS 애플리케이션 배포**: 자동화된 배포 파이프라인
- **Application 모니터링**: 애플리케이션 성능 및 상태 모니터링
- **실시간 알림 시스템**: 문제 발생 시 즉시 알림

#### 4교시: GCP 클러스터 통합 모니터링 (90분)
- **GCP GKE 클러스터 구축**: GCP Kubernetes 환경 설정
- **GCP Infrastructure/Platform 모니터링**: GCP 환경 모니터링
- **멀티 클라우드 통합 모니터링**: AWS + GCP 통합 관리

#### 5교시: AWS ECS 고급 배포 (90분)
- **Application Load Balancer 설정**: 로드 밸런싱 및 트래픽 관리
- **자동 스케일링**: 트래픽에 따른 자동 확장/축소
- **Blue-Green, Canary 배포**: 무중단 배포 전략

#### 6교시: GCP Cloud Run 고급 배포 (90분)
- **도메인 매핑**: 사용자 정의 도메인 설정
- **트래픽 분할**: 카나리 배포 및 트래픽 관리
- **서버리스 최적화**: 비용 효율적인 서버리스 아키텍처
