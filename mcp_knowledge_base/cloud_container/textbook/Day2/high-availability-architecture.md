# 고가용성 아키텍처 가이드


## 개요

["개요"]["#개요"]
이 가이드는 Cloud Container 2일차의 고가용성 아키텍처 설계 실습을 위한 상세 가이드입니다.

## 학습 목표

["학습 목표"]["#학습-목표"]
- Multi-AZ/Multi-Region 아키텍처 이해
- 고가용성 설계 원칙 학습
- 실제 서비스 시나리오 아키텍처 구현

## 실습 내용

["실습 내용"]["#실습-내용"]
1. **Multi-AZ 구성**
   - AWS: 여러 가용 영역에 리소스 분산
   - GCP: 여러 리전에 리소스 분산

2. **로드 밸런싱 설정**
   - Application Load Balancer 구성
   - Cloud Load Balancing 설정

3. **자동 복구 시스템**
   - Health Check 설정
   - Auto Scaling 정책 구성
