## 🛠️ 기술 스택

### 컨테이너 오케스트레이션
- **Kubernetes** - 컨테이너 오케스트레이션
- **AWS ECS/Fargate** - 서버리스 컨테이너 실행
- **GCP GKE** - Google Kubernetes Engine
- **Helm** - 패키지 관리 및 배포

### 고가용성 기술
- **AWS Multi-AZ** - 가용 영역 분산
- **GCP Multi-Region** - 지역 분산
- **Load Balancing** - 트래픽 분산
- **Auto Scaling** - 자동 확장

### 모니터링 & 로깅
- **Prometheus + Grafana** - 메트릭 수집 및 시각화
- **ELK Stack** - 로그 수집 및 분석
- **AWS CloudWatch** - 클라우드 모니터링
- **GCP Monitoring** - Google Cloud 모니터링
