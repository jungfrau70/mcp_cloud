## 과정명
**Kubernetes 및 GKE 고급 오케스트레이션**

## 과정 개요
Cloud Master 과정을 수료한 학습자를 위한 고급 과정으로, Kubernetes 오케스트레이션, 고가용성 아키텍처, 엔터프라이즈급 운영을 학습합니다.

## 학습 목표
- Kubernetes 클러스터 아키텍처 이해
- GKE 클러스터 생성 및 고급 설정
- 마이크로서비스 아키텍처 구성
- ECS Fargate 서비스 배포

## 과정 구성
- **Day 1**: Kubernetes 및 GKE 고급 오케스트레이션
- **Day 2**: 고가용성 및 확장성 아키텍처

## 선수 요구사항
- Cloud Master 과정 수료
- Docker, Git/GitHub, CI/CD 실습 경험

## 수료 기준
- 모든 실습 완료
- Kubernetes 오케스트레이션 능력 확인
- 고가용성 아키텍처 설계 능력 확인
